How this site runs

This page is served from a virtual private server I provisioned and hardened myself. Nothing here is managed hosting.

host
Akamai Cloud VPS, Rocky Linux 10
web
Caddy, with automatic certificate issuance and renewal from Let's Encrypt
network
Cloudflare DNS and registrar, DNSSEC enabled, SPF and DMARC set to reject
security
Key-only SSH with root login disabled, firewalld on the host behind a cloud firewall, SELinux enforcing, automatic security patching
